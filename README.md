# SONAR – Rock vs Mine Prediction

## Project Overview
This project uses Machine Learning to classify underwater objects as Rocks or Mines based on SONAR signal measurements.

## Algorithm
Logistic Regression

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Dataset Collection
2. Data Exploration and Analysis
3. Data Preprocessing
4. Train-Test Split
5. Logistic Regression Model Training
6. Model Evaluation
7. Rock vs Mine Prediction
8. Model Saving using Pickle

## Model Performance
- Training Accuracy: 83.73%
- Testing Accuracy: 85.71%

## Evaluation
The model was evaluated using:
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score

## Project Environment
Implemented using Google Colab.

## Objective
To demonstrate how Machine Learning can analyse SONAR signal patterns and classify underwater objects into Rock and Mine categories.
